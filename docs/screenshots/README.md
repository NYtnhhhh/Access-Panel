# 📸 Скриншоты

Положи сюда 3 скриншота:

| Файл | Что показать |
|------|--------------|
| `main.png` | Главное окно с поиском и списком игроков |
| `card.png` | Карточка игрока с наказаниями |
| `settings.png` | Боковая панель настроек |

**Как сделать:**

1. Запусти приложение (`cargo run --release`).
2. Открой нужное окно.
3. **Windows:** `Win + Shift + S` → выдели область → сохрани.
4. **Linux:** `PrtSc` или Spectacle.
5. Обрежь до размера окна, сохрани как PNG.
